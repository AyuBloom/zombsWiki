# `_MakeBlendField` Overview

Zombs.io employs an original method to validate players via Proof of Work (PoW) challenges that the client has to solve in order to enter a server and maintain a connection. It is a measure to occupy RAM and CPU resources of the client and, therefore, increase multiboxing costs.

This section of the wiki aims to provide an understanding of both the inner workings of `_MakeBlendField`, and the wrapper (around the WebAssembly module) of `_MakeBlendField` that is used in the game.
